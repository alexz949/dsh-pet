# 示例干员

两个做好的宠物包，装上就能看效果：

| 干员                               | 内容                                                                                               |
| ---------------------------------- | -------------------------------------------------------------------------------------------------- |
| 维什戴尔·绝对主角（`op-791acf0d`） | 基建动作 + 战斗动作：出场、攻击B、技能1、技能2·过载、技能3；Claude Code / Codex / DSH 干活时会开打 |
| 逻各斯·辉煌的静谧（`op-dc41fbe3`） | 基建动作：待机、走路、互动、坐着、睡觉、特别动作                                                   |

## 安装

把想要的干员的 `<id>-config.json` 和 `<id>-animation/` 一起复制到 `~/.dsh/dsh-pet/pet/`，然后右键任意桌宠 →「更多」→「重载配置」（或重启桌宠）。

```sh
cp -R samples/op-791acf0d-* ~/.dsh/dsh-pet/pet/
```
